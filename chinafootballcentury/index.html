本政策仅适用于本游戏自身提供的功能。您通过 TapTap、应用商店、浏览器、QQ 或其他第三方平台 下载、更新、评价、分享本游戏或联系开发者时，相关平台可能按照其自身的隐私政策处理您的信息， 该等处理行为不属于本游戏直接收集或处理信息的范围。

二、我们如何收集和使用信息

（一）个人信息

本游戏当前不提供账号注册、登录、实名认证、充值、广告、云存档或在线社交功能， 不会主动收集您的姓名、手机号、身份证号、设备标识符、位置信息、通讯录、短信、通话记录、 相册、麦克风、摄像头等个人信息。

（二）本地游戏数据

为提供保存和继续游戏等基本功能，本游戏会在您的设备本地保存：

  • 游戏进度、比赛结果及与游戏进程有关的统计数据；
  • 球员、阵容、培养、地区建设等游戏状态；
  • 自动存档、手动存档及存档槽信息；
  • 音量、显示、操作或其他游戏设置。

上述数据仅用于在您的设备上恢复游戏进度和保留设置，不会由我们上传至服务器， 也不会用于识别您的真实身份。您可以通过游戏内相关功能、设备系统的清除数据功能或卸载游戏删除这些数据。

（三）设备权限

本游戏当前不会申请联网、网络状态、位置、通讯录、短信、电话、相册、麦克风或摄像头权限。 若未来版本因新增功能需要申请新的权限，我们会在申请前说明用途，并依法征得您的同意。

（四）联系开发者

当您主动点击游戏内“联系开发者”并选择加入玩家交流群时，本游戏会调用设备系统能力， 打开 QQ 加群页面。该操作不会将您的本地游戏存档上传给我们。QQ 或浏览器可能按照其自身规则处理 网络地址、设备信息或账号信息，请您在访问前查看对应第三方平台的隐私政策。

如果您主动通过电子邮件或 QQ 与我们联系，我们会收到您主动提供的联系方式和沟通内容， 仅用于回复咨询、处理反馈或解决问题。除法律法规另有规定外，我们会在完成相应事项后于合理期限内删除或匿名化处理。

三、Cookies 和同类技术

本游戏不使用 Cookies 或同类技术。本隐私政策页面为静态网页，不包含广告、用户统计或行为追踪脚本。 GitHub Pages 作为网页托管服务可能基于安全和基础运维需要处理必要的访问日志，具体规则以 GitHub 的隐私声明为准。

四、第三方 SDK 与服务

本游戏当前未接入广告、统计、登录、社交、支付、推送、云存档等第三方 SDK。 除您主动打开 QQ 加群页面，以及通过 TapTap 或其他应用商店获取本游戏外， 本游戏不会主动向第三方共享您的个人信息。

若未来版本接入第三方 SDK 或新增联网服务，我们将在相关功能上线前更新本政策， 明确披露第三方名称、处理目的、信息类型和第三方隐私政策链接，并依法取得您的授权同意。

五、信息的保存

本游戏当前不会在我们的服务器上保存您的个人信息。游戏存档及设置保存在您的设备本地， 保存期限由您决定。卸载游戏、清除应用数据、刷机或更换设备可能导致本地数据丢失，请您妥善管理设备和存档。

对于您主动通过电子邮件或 QQ 提供的信息，我们仅在处理咨询、反馈、争议或履行法定义务所需的期限内保存。

六、信息的共享、转让与公开披露

我们不会出售您的个人信息，也不会向第三方共享、转让或公开披露您的个人信息，但以下情况除外：

  • 获得您的明确同意；
  • 根据法律法规、司法程序或行政主管部门的合法要求；
  • 为保护您、其他个人或公众的生命、财产等重大合法权益所必需；
  • 发生合并、收购、资产转让或类似交易，并依法向您告知相关情况。

七、信息安全

我们会采取与本游戏实际情况相适应的安全措施保护信息。由于本游戏的存档仅保存在您的设备本地， 请您妥善保管设备、系统账号及解锁凭证。互联网环境并非绝对安全；当您通过电子邮件、QQ 或其他网络服务联系我们时， 请避免发送与问题处理无关的敏感个人信息。

八、您的权利

本游戏不提供账号系统，因此不存在游戏账号注销入口。您可以通过游戏内功能、设备系统设置中的清除数据功能， 或卸载游戏删除本地游戏数据。

如果您曾主动向我们提供个人信息，可以通过本政策载明的联系方式提出查询、更正、复制或删除请求。 我们会在核实您的身份后，于法律法规规定的期限内处理。

我们重视未成年人个人信息保护。未成年人应在监护人阅读并同意本政策后使用本游戏。 本游戏不会主动收集未成年人的个人信息。如果监护人发现未成年人在未经同意的情况下向我们提供了个人信息， 请通过本政策载明的方式联系我们，我们将在核实后依法处理。
